# Core User Flows

## Initial Setup

1. Sign up.
2. Create company workspace.
3. Configure fiscal year, currency, industry, and organization dimensions.
4. Invite users.
5. Assign roles and scopes.
6. Select data source.
7. Upload Excel/CSV or enter initial data.
8. Map source fields.
9. Validate data.
10. Publish actuals to the financial model.
11. Configure planning assumptions.
12. Create first budget.
13. Generate first forecast.
14. Open executive dashboard.

## Monthly FP&A Cycle

1. Collect actuals and departmental submissions.
2. Validate and resolve data issues.
3. Close/lock the relevant period when approved.
4. Refresh actual performance.
5. Compare actual vs budget and forecast.
6. Identify material variances.
7. Explain drivers.
8. Update rolling forecast.
9. Run scenarios where needed.
10. Review cash outlook and risks.
11. Assign management actions.
12. Publish management report.

## Budget Approval

Draft → Submitted → Under Review → Approved → Locked

Changes after approval require a controlled new version or adjustment workflow rather than silent editing.

## Import Flow

Upload → File Validation → Column Mapping → Data Validation → Preview → Import → Reconciliation Summary → Publish

## Scenario Flow

Select baseline → Clone assumptions → Change drivers → Recalculate model → Compare outputs → Save scenario → Share/review → Decide

## AI Flow

User question → Authorization check → Retrieve relevant governed financial data/model context → Calculate or query deterministic metrics → Generate explanation → Cite internal model elements → Return answer

AI must not bypass tenant permissions or use another organization's data.
